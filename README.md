# ☕ LEAP COFFEE - POS & Daily Management System

ប្រព័ន្ធគ្រប់គ្រងហាងកាហ្វេ និងអាហារដ្ឋាន (POS System & Daily Income/Expense Tracker) បង្កើតឡើងដោយប្រើប្រាស់ PHP, MySQL និង Tailwind CSS ជាមួយទម្រង់អក្សរខ្មែរ (Kantumruy Pro)។

## ✨ មុខងារសំខាន់ៗ (Key Features)

* **💻 ប្រព័ន្ធលក់ (POS System - `menu.php`):**
  * គ្រប់គ្រងតុភ្ញៀវចំនួន 8 តុ (រក្សាទុកការកុម្ម៉ង់បណ្តោះអាសន្នតាមតុនីមួយៗ)
  * បែងចែកប្រភេទមុខទំនិញ៖ កាហ្វេ (Coffee), តែ (Tea), ភេសជ្ជៈ (Drinks), និងម្ហូបអាហារ (Food)
  * ជម្រើសបន្ថែម (Options)៖ កម្រិតស្ករ (0% - 100%), បន្ថែមគ្រាប់កាហ្វេ (Shots), ទំហំដូង, និងជម្រើសបាយ
  * គណនាប្រាក់ទទួល និងប្រាក់អាប់ដោយស្វ័យប្រវត្តិទាំងប្រាក់ដុល្លារ ($) និងប្រាក់រៀល (៛) (អត្រា 1$ = 4,000៛)
  * មុខងារកត់ត្រាអតិថិជនជំពាក់ប្រាក់ (Debt Tracking) និងទូទាត់សងប្រាក់វិញ
  * មើលប្រវត្តិការលក់ប្រចាំថ្ងៃ កែប្រែ និងលុបវិក្កយបត្រ

* **📊 ប្រព័ន្ធគ្រប់គ្រងចំណូល-ចំណាយប្រចាំថ្ងៃ និងប្រចាំខែ (`index.php` & `form.php`):**
  * កត់ត្រាចំណូលពីការលក់កាហ្វេ និងបាយប្រចាំថ្ងៃ
  * កត់ត្រាចំណាយលម្អិត (មាន់, ត្រី, បន្លែ, ពង, សាច់, គ្រឿងទេស, សាប៊ូ, សាំង, ហ្គាស, អគ្គិសនី, គ្រាប់កាហ្វេ, ទឹកដោះគោ, ដូង, ទឹក, ប្រាក់ខែបុគ្គលិក និងចំណាយផ្សេងៗ)
  * បញ្ចូលទិន្នន័យបានទាំងប្រាក់រៀល (៛) និងប្រាក់ដុល្លារ ($) ដោយបំប្លែងតម្លៃស្វ័យប្រវត្តិ
  * បូកសរុបរបាយការណ៍ចំណូល ចំណាយ និងប្រាក់ចំណេញសុទ្ធប្រចាំខែដោយស្វ័យប្រវត្តិ

## 📁 រចនាសម្ព័ន្ធឯកសារ (Project Files)

* `login.php` - ទំព័រចូលប្រើប្រាស់ប្រព័ន្ធ (ពាក្យសម្ងាត់លំនាំដើម៖ `123`)
* `index.php` - ផ្ទាំងគ្រប់គ្រងរបាយការណ៍ចំណូល-ចំណាយប្រចាំថ្ងៃ និងប្រចាំខែ
* `form.php` - ទម្រង់បញ្ចូល និងកែប្រែទិន្នន័យចំណូល-ចំណាយប្រចាំថ្ងៃ
* `menu.php` - ប្រព័ន្ធលក់ទំនិញ LEAP COFFEE POS System
* `db.php` - ឯកសារភ្ជាប់ទៅកាន់មូលដ្ឋានទិន្នន័យ MySQL
* `database.sql` - ឯកសារសម្រាប់បង្កើតតារាងទិន្នន័យ (Database Schema)

## 🚀 របៀបដំឡើង (Installation Guide)

1. **ដំឡើងកម្មវិធី Server ក្នុងកុំព្យូទ័រ៖** ដំឡើងកម្មវិធីដូចជា XAMPP, WAMP, ឬ Laragon។
2. **ដាក់ឯកសារកូដ៖** ចម្លង (Copy) Folder កូដនេះទៅដាក់ក្នុង `htdocs` (សម្រាប់ XAMPP) ឬ `www` (សម្រាប់ WAMP/Laragon)។
3. **បង្កើត Database៖**
   * បើកកម្មវិធី **phpMyAdmin** (`http://localhost/phpmyadmin`)
   * បង្កើត Database ថ្មីឈ្មោះថា `coffee_shop_db` (ឬ Import ឯកសារ `database.sql` ចូលតែម្តង)។
4. **កំណត់ការភ្ជាប់ Database (`db.php` និង `menu.php`)៖**
   * កែប្រែ `$username` និង `$password` ឱ្យត្រូវតាម MySQL របស់អ្នក៖
     ```php
     $host = 'localhost';
     $dbname = 'coffee_shop_db';
     $username = 'root';
     $password = '123456789'; // ដាក់ទទេ '' ប្រសិនបើ XAMPP របស់អ្នកគ្មាន Password
     ```
5. **បើកដំណើរការ៖** ចូលទៅកាន់ Browser ហើយវាយ `http://localhost/ឈ្មោះ_folder_របស់អ្នក/login.php`។
